# 🛕 Virasat Pulse — Delhi Heritage Exploration

> **Unfold the Living History of Bharat**
> An interactive, gamified heritage exploration platform designed for Gen Z, bringing ancient monuments, subterranean stepwells, and oral traditions to life.

---

## 🌟 Overview

**Virasat Pulse** reimagines static museum pages and textbook history into story-driven **Heritage Trails**. Explorers traverse historic citadels, solve architectural riddles, listen to authentic audio folklore, and earn digital relic badges as they level up.

### Capital Edition Highlights (Delhi Heritage)
- **Qutub Minar & Iron Pillar Sanctuary (Mehrauli)** — Unravel the 1,600-year-old rustless metallurgy of Chandragupta II's iron pillar.
- **Red Fort / Lal Qila (Old Delhi)** — Walk through Lahori Gate, Chhatta Chowk covered bazaar, and marble pavilions of Shahjahanabad.
- **Humayun’s Garden Tomb (Nizamuddin)** — Discover South Asia's first monumental Charbagh garden tomb that inspired the Taj Mahal.
- **Agrasen Ki Baoli (Connaught Place)** — Descend 108 stone steps into Delhi's subterranean water harvesting sanctuary.

---

## ✨ Features

- **🗺️ Interactive Heritage Trails**: Spatial exploration of Delhi's top historic monuments.
- **📜 Oral Traditions & Audio Lore**: Authenticated folklore, myth-vs-fact checkers, and voice-narrated stories.
- **🎯 Cultural Quizzes & Badges**: Earn XP, unlock digital relics, and track your explorer level (`Lvl 3 • 450 XP`).
- **🎨 Ancient Meets Modern Aesthetic**: Crafted with warm terracotta (`#C85A32`), antique gold (`#D4AF37`), sandstone parchment (`#F7F3E9`), and custom heritage typography (`Cinzel` + `Plus Jakarta Sans`).

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 + Custom Heritage CSS Design Tokens
- **Routing**: React Router DOM v7
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Maps**: Leaflet + React-Leaflet

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation & Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/trishagarg22/Virasat-Pulse.git

# 2. Navigate to project directory
cd Virasat-Pulse

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser to start exploring!
